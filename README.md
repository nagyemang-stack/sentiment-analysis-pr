## Overview

This project demonstrates how PR professionals can use data analytics to track brand perception across social media platforms. It processes real-world social media data through a dual sentiment analysis engine (TextBlob + VADER), generates interactive visualizations, and produces an executive-ready report.

The analysis covers 824 social media posts across 5 platforms over an 8-week period, tracking sentiment trends, keyword frequency, and platform-level engagement patterns.

## Methodology

**Sentiment Scoring:** Each post is analyzed using two independent NLP engines:

1. **TextBlob** — Provides polarity scores (-1.0 to +1.0) based on word-level sentiment lexicons
2. **VADER** — Optimized for social media text, handles slang, emoji, and punctuation intensity

The hybrid score averages both engines for more robust classification. Posts scoring above +0.05 are classified as positive, below -0.05 as negative, and between as neutral.

**Why this matters for PR:** Sentiment analysis transforms qualitative brand perception into quantifiable metrics that can be tracked over time, compared across campaigns, and presented to stakeholders with confidence.

## Adapting for Real Data

To use with real social media data, replace the `generate_social_data()` function with data from:

- Twitter/X API (via Tweepy or Twitter API v2)
- Instagram Graph API
- Reddit API (via PRAW)
- Brandwatch, Sprout Social, or Mention exports (CSV)

The analysis pipeline remains identical — only the data source changes.
